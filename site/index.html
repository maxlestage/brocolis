Brocolis 🥦

Proxy MITM Rust pour le chiffrement sélectif de votre trafic web.

Marquez ((votre secret)) dans vos messages : Brocolis le chiffre en AES-256-GCM avant qu'il ne quitte votre machine, et le déchiffre pour les utilisateurs qui partagent votre clé. Twitter, forums, messageries — sans rien changer côté serveur.

Télécharger pour macOS

Une commande, zéro configuration

sudo brocolis auto
  • Mot de passe administrateur demandé une seule fois (frontière de sécurité macOS)
  • Génère un certificat racine et l'approuve dans le trousseau Système (Safari, Chrome)
  • Active la confiance entreprise pour Firefox (toutes variantes détectées), ou dépose un profil brocolis-firefox.mobileconfig à approuver dans Réglages Système — sans modifier le bundle Firefox
  • Règle le proxy web et HTTPS du système
  • Démarre le chiffrement sélectif AES-256-GCM
  • Restaure exactement l'état initial à l'arrêt (Ctrl-C) : CA retiré, profil et politiques retirés, proxy remis comme avant

Sans sudo ou hors macOS, brocolis auto démarre le proxy sans toucher au système (équivalent à --no-system) : pointez votre navigateur sur 127.0.0.1:<port> manuellement.

Fonctionnalités

Chiffrement sélectif

Seuls les segments ((entre doubles parenthèses)) sont chiffrés, en AES-256-GCM, sous la forme d'un jeton [[BROCOLIS:v1:…]]. Le serveur distant ne stocke que du chiffré.

MITM transparent

Interception HTTPS via CONNECT, certificats feuilles forgés à la volée par une autorité interne (rcgen), TLS terminé côté client avec rustls.

Clés partagées

Une clé symétrique 256 bits, partagée par canal sûr. Rotation immédiate via SIGHUP, rechargement via SIGUSR1.

Multi-navigateurs

Safari, Chrome (trousseau Système) et toutes les variantes Firefox (politique entreprise ou profil .mobileconfig sans modification de bundle) font confiance au CA automatiquement.

Démarrage rapide

  1. Téléchargez l'archive brocolis-macos-universal.tar.gz via le bouton ci-dessus (binaire universel Intel + Apple Silicon).
  2. Lancez sudo brocolis auto. Le mot de passe administrateur n'est demandé qu'une fois (frontière de sécurité macOS).
  3. Tapez vos messages en marquant ce qui doit rester privé : ((mon secret)). Vos correspondants partageant la clé voient le clair ; tous les autres ne voient que du chiffré.
  4. Ctrl-C pour tout arrêter : Brocolis remet votre système exactement dans son état initial.

Compiler depuis les sources & CLI manuel

Pour utiliser Brocolis hors macOS, ou tout piloter à la main :

# Compiler (Rust stable, depuis les sources)
cargo build --release          # binaire : target/release/brocolis

# 1. Générer une clé symétrique AES-256 (à partager par canal sûr)
$ brocolis keygen
SomopQcHJyVQQAWedZFGY5E4+hxKjZemOB7aGnYr6kw=

# 2. Exporter le certificat racine pour l'installer dans le navigateur
$ brocolis ca --export brocolis-ca.crt

# 3. Lancer le proxy (clé renseignée dans brocolis.toml, cf. brocolis.example.toml)
$ brocolis run --config brocolis.toml
Brocolis écoute sur http://127.0.0.1:8080 (proxy HTTP/HTTPS)

Sur Unix, la gestion des clés se pilote par signaux : SIGHUP régénère la clé (rotation en cas de compromission), SIGUSR1 recharge la clé partagée depuis le fichier de configuration.

Comment ça marche

Brocolis s'intercale entre votre navigateur et le service en ligne. À l'envoi, il chiffre les segments marqués ; à la réception, il déchiffre les jetons lisibles avec la clé partagée.

Navigateur ─►  Brocolis (proxy local)  ─►  Serveur distant
                       │                              │
   « salut ((secret)) » ───► « salut [[BROCOLIS:v1:…]] » (chiffré sur le fil)
   « salut secret »     ◄─── « salut [[BROCOLIS:v1:…]] » (déchiffré pour vous)

Vie privée et sécurité

  • Chiffrement de bout en bout entre utilisateurs partageant la clé — le service distant ne voit jamais le clair.
  • Aucune télémétrie, aucun serveur, aucun compte — tout tourne en local.
  • Le CA est retiré du trousseau automatiquement à l'arrêt s'il a été ajouté par Brocolis.
  • Code source consultable pour audit (logiciel sous licence propriétaire).
